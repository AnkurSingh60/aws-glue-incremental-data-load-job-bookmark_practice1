# AWS Glue Incremental Data Load

## Project Overview
This project demonstrates Incremental Data Loading using AWS Glue, S3, Glue Crawler, Data Catalog and PySpark.

## AWS Services Used
- Amazon S3
- AWS Glue
- Glue Crawler
- Glue Data Catalog
- CloudWatch

## Workflow
S3 → Glue Crawler → Data Catalog → Glue Job → CloudWatch

## Result
Successfully read data from Glue Catalog and processed it using PySpark.
